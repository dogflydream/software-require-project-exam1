# 绿循校园 V2.1.0 本地测试指南

更新时间：2026-11-07。首页为 http://127.0.0.1:8000/，接口文档为 http://127.0.0.1:8000/docs。

## 启动与刷新

在项目根目录运行：

```powershell
.venv\Scripts\python.exe -m uvicorn main:app --reload --host 127.0.0.1 --port 8000
```

修改前端源码后运行 `bun run --cwd web build`，然后刷新网页；后端自动重新加载 Python 修改。服务仅监听本机。不要删除或重置有人工测试数据的 `campus.db`。

## 推荐网页验收路线

1. **浏览搜索**：未登录搜索“台灯”，切换分类和价格排序，刷新应保留条件。搜索不存在的词应显示空态，重置后恢复列表。手机宽度检查底部导航、分类换行及内容无遮挡。
2. **发布图片**：张绿循发布物品并上传图片，成功后积分 +10；零价格显示“免费赠送”。编辑并移除图片后应转待审核，个人中心显示待审。
3. **审核**：管理员在“物品审核”点入详情核对，再通过或填理由驳回。物主能看到意见，修改后重新审核。已下架物品审核通过后仍需单独恢复上架。
4. **预约自提**：李循环预约张绿循的在售物品，张绿循在“我卖出的”确认。双方从订单查看联系方式。线下验货后点击完成，试空码/错码应失败且状态不变；勾选确认并填正确码后完成，卖家 +20 分、物品循环 +1，按钮消失。
5. **取消治理**：另建预约，进行中状态编辑/下架应提示先取消订单。管理员下架会同时取消订单；刷新双方订单核对状态，物品不可自行重新出现在市集。已完成物品不提供下架操作。
6. **兑换凭证**：足够积分的账号兑换礼品，余额和库存同步减少。从商城“我的兑换记录”查看礼品、积分、时间与 `GC-GIFT-...` 凭证，另一账号不可见。凭证用于办公室线下核对，没有线上核销或已领取状态。
7. **收藏举报**：收藏非本人物品后在个人中心取消；提交至少 2 字举报，管理员处理后举报人应看到“已处理”。
8. **资料隐私**：编辑联系方式并从对方进行中订单查看，公开主页不可见；订单完成/取消后不再返回联系方式。改密码后全部会话失效，重新登录。
9. **后台配置**：新增分类后发布表单可用；重命名同步引用；有物品引用的分类不可删除，“其它”不可删除。调整礼品库存与积分价后在商城核对。
10. **绿色大屏**：完成流转后刷新看板，核对循环次数、减碳量和排行榜。减碳量来自分类系数估算，属于演示指标。

## 自动测试

独立测试使用临时数据库，直接运行：

```powershell
.venv\Scripts\python.exe -m unittest tests_market_regression tests_workflow_regression -v
```

原认证测试固定连接 8011，会改动密码和数据，需两个终端运行隔离服务。不要指向当前人工验收数据库。

```powershell
# 终端 1：项目根目录
@'
import tempfile
from pathlib import Path
import database, main, uvicorn
with tempfile.TemporaryDirectory(prefix="campus-auth-test-") as folder:
    database.DB_PATH = Path(folder) / "campus.db"
    main.UPLOAD_DIR = Path(folder) / "uploads"
    uvicorn.run(main.app, host="127.0.0.1", port=8011)
'@ | .venv\Scripts\python.exe -

# 终端 2：项目根目录
.venv\Scripts\python.exe -X utf8 tests_auth_regression.py
```

验证基线：15 个独立回归测试、147 项认证断言及前端生产构建通过。自动回归不能替代浏览器中的跨账号交接、布局和可访问性检查。
